# Cozy Treasure Hunter: project brief

Paste this into the instructions of a Claude project so that conversations there start with the full picture.

## The game

Cozy Treasure Hunter is a calm first-person PC game about a long beach, a metal detector and a very good dog. There is no timer and no way to lose. You sweep the sand, dig up finds, clean them by hand, sell or recycle them, return lost items, and slowly build up a camp.

- **Beyond the beach:** a golf cart, a boat, three small islands (a green one with ruins, a ring of sand around a lagoon, a volcanic rock), diving to a shipwreck, and a message in a bottle that leads to a hidden hatch.
- **The story:** Captain Holt's ship, the Marigold, was lost with a town's gold and its church bell. His journal is in a stone room under the dunes.
- **The ending:** assemble the Pirate Medallion and the Ancient Astrolabe (three buried shards each), then open the great door at midday, when sunlight comes down a shaft onto the lock. Stairs lead to a sea cave with a dead monster's skeleton around 30,000g of gold. An ending card follows, play continues, and a Luxury shop tab opens.
- **Controls:** keyboard and mouse, or a full controller.

## Technology

- Vite, strict TypeScript and Three.js, packaged with Electron. Models are almost entirely generated by code.
- Code: https://github.com/armenazizbek/cozy-beach (branch `main`)
- `npm run dist:steam` builds `release/win-unpacked`.
- Music is six MP3 tracks in `public/music`. The radio plays everywhere once it is on, and follows the location.
- **Unity port (in progress):** `unity/` is a Unity 6.3 LTS (`6000.3.28f1`, URP) project that ports the game file by file to C#, with a small C# copy of Three.js underneath, so it can later reach consoles. See `unity/MIGRATION.md` and `unity/PORT_STATUS.md`. Changes to the TypeScript game need the same change in the matching C# file.

## Decisions already made

- **Multiplayer:** not now. If it ever happens: 2-player online co-op in the host's world, with invite codes that work across stores, and no split-screen.
- **Order of platforms:** PC and Steam, then Steam Deck, then Android and iOS, then VR or consoles depending on sales.
- **Consoles:** need a rebuild in another engine, because Electron does not run there. Only worth it if PC sales are strong.
- **Phones:** possible without a rewrite, using an app wrapper, but touch controls and heat are the main work.
- **VR:** a good fit but a big job. A quick WebXR test on a real headset would be the first step, after the PC release. Valve's new headset makes this worth another look later.
- **FSR 1:** possible as an option next to Render Scale, but not needed for now.
- **Price:** $4.99 launch, with a 10% launch discount.
