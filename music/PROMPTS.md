# Music prompts for Cozy Treasure Hunter

Six tracks, one prompt each. Paste a prompt into your music tool (Suno, Udio, Stable Audio or similar), make 6 to 10 versions, and keep the best one.

Put the finished files in `public/music/` with exactly these names (MP3 or OGG, under 5 MB each):

| File | Where it plays |
|---|---|
| `01-main-theme.mp3` | Main menu and the start of the game |
| `02-beach-day.mp3` | The beach and camp during the day |
| `03-camp-night.mp3` | The camp and beach at night |
| `04-underwater.mp3` | Diving |
| `05-underground.mp3` | The stone room under the dunes |
| `06-ending.mp3` | The end of Part One |

Make sure the tool's plan allows commercial use, and keep the receipt or terms with the files.

---

## 01 Main theme

```
Cozy instrumental video game main theme, warm and inviting, 78 BPM, a quiet seaside morning with golden light.
Fingerpicked nylon-string acoustic guitar carries a simple, memorable, singable melody, supported by soft marimba, kalimba,
warm upright bass, light brushed percussion and a gentle ukulele. A soft flute answers the melody in the second half, with
a little vibraphone shimmer. Major key, hopeful and nostalgic, slow and spacious, unhurried.
Seamless loop with a gentle fade at the end. Instrumental only: no vocals, no lyrics, no heavy drums, no sudden changes.
About 2.5 minutes. Style: lo-fi acoustic, indie folk, cozy game soundtrack.
```

## Tips

- Generate the main theme first. For the others, you can add "the same melody idea as a gentle seaside theme" so the game sounds like one world.
- Loops: cut the best section so the end flows into the start. A seam you can't hear is better than a long track.
- If the tool keeps adding vocals, add "instrumental, no voice, no humming" at the start of the prompt.
- If it is too busy, add "minimal, sparse, slow, lots of space".
